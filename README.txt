HomeConnect Canada - standalone demo site

Put it online (free, about 2 minutes):
1. Go to https://app.netlify.com/drop
2. Drag this whole folder (or the zip) onto the page.
3. Netlify gives you a link. Send that link to friends.

Install on a phone: open the link, then
 - iPhone: Safari > Share > Add to Home Screen
 - Android: Chrome menu > Install app

Notes: data stays on each person's own device. Shelters and providers are fictional.
Use made-up names and phone numbers.
